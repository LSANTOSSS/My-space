## Publicar com GitHub Pages

1. Abra https://github.com/LSANTOSSS/My-space/settings/pages.
2. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)**.
4. Clique em **Save**.
5. Aguarde o GitHub informar a URL publicada nessa mesma tela.

A publicação pelo GitHub Pages exige essa ativação inicial, indisponível pelas ferramentas conectadas desta sessão. Depois da ativação, alterações na branch main são publicadas pelo GitHub.
